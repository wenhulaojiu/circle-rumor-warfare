# 圈层谣言攻防战
https://rumor.okethan.com
## Windows 一键启动

安装 Node.js 18 或更高版本后，直接双击项目目录中的 `启动游戏.bat`，脚本会自动启动服务并打开浏览器。不要关闭后台服务窗口，否则游戏会停止。

一款关于信息在社交关系网里怎么传、怎么被拦住的小游戏。

你扮演**造谣方**或**辟谣方**，在由兴趣圈、家长圈、职场圈、校园圈组成的交叉关系网里投放话术。
四个圈层**部分重叠、部分独立** —— 相邻的圈有交集区（信息能顺着过），对角的圈之间只有几条很弱的
连接（信息很难过）。能不能跨过那道边界，基本就决定了这局谁赢。

> 全部主题、人物、数据均为虚构游戏设定，不对应任何真实事件、企业或个人。

---

## 跑起来

```bash
node server.js          # 或 npm start
```

打开 <http://localhost:5173> 即可。**不需要 `npm install`** —— 整个项目零第三方依赖，
只用 Node 内置模块（`http` / `fs` / `path`）和浏览器原生 API。断网也能完整游玩。

换端口：`PORT=8080 node server.js`

## 大模型接入（可选）

话术评分有两条路径，共用同一份输出结构，可随时互换：

| 引擎 | 何时启用 | 特点 |
|---|---|---|
| **大模型** | 检测到凭证时 | 语义理解强，能指出"89/120 对不上 73.6%"这种具体破绽 |
| **本地规则引擎** | 无凭证，或大模型调用失败时 | 零延迟、离线可用；同时还是 AI 对手的行动评分器 |

**没配凭证也能玩**，会自动降级到本地规则引擎，游戏功能完全不受影响。

### 配置方式

复制 `config.example.json` 为 `config.local.json` 并填入：

```json
{
  "baseUrl": "https://api.deepseek.com/anthropic",
  "authToken": "你的密钥",
  "model": "deepseek-v4-flash",
  "maxTokens": 2000,
  "timeoutMs": 45000,
  "temperature": 0.3,
  "scoringEngine": "auto"
}
```

也可以直接用环境变量，**环境变量优先级高于文件**：

```bash
ANTHROPIC_BASE_URL=... ANTHROPIC_AUTH_TOKEN=... ANTHROPIC_MODEL=... node server.js
```

`config.local.json` 已经在 `.gitignore` 里，不会被提交。启动时会打印凭证来源和一次探活结果。

`scoringEngine` 可以设成 `"local"` 强制离线评分、`"llm"` 强制走大模型、`"auto"`（默认）自动选择。

## 玩法

**每回合**你选 3 个节点，为每个节点单独写一段话术。AI 对手同样投 3 个。一局 6 回合。
第 3 回合会触发一次中局事件，改变各圈层的易感度。

### 六种话术 × 三个维度

写什么内容决定了它偏重哪个维度 —— 这是这个游戏的核心机制：

| 话术类型 | 即时影响 | 时间留存 | 破圈广度 | 识别特征 |
|---|:---:|:---:|:---:|---|
| 情绪化标题 | ●●● | ○ | ● | 震惊、速看、太可怕、不转不是… |
| 伪造数据 | ●● | ●●● | ○ | 百分比、倍数、抽检、数据显示 |
| 权威背书 | ●● | ●●● | ● | 专家、内部人士、红头文件、我朋友在医院 |
| 诉诸恐惧 | ●●● | ● | ●● | 致癌、中招、为了家人、后悔一辈子 |
| 模糊信源 | ○ | ● | ●●● | 据说、网传、疑似、某 |
| 破圈投放 | ○ | ● | ●●● | 转给、扩散、让更多人知道 |

系统会识别你写的话术属于哪一类（大模型做语义判断 / 本地正则+权重），再结合**目标节点的画像**
算契合度。每个节点有四个画像维度：怀疑度、从众度、权威信任、恐惧敏感。
**打错软肋的话术事倍功半** —— 悬停节点就能看到该节点最吃哪一套。

### 辟谣方的反噬

辟谣方如果去**伪造数据**或**诉诸恐惧**，会被判定为反噬：这个节点之后对你的话术更警惕
（接受度打 0.68 折）。辟谣不是靠把嗓门喊得比谣言更大。

### 传播与免疫

投放完，节点会顺着连接关系把状态推给邻居。圈内边强、桥接边中、跨圈边弱且跨圈更难。

- **谣言外溢**：相信度越高的节点，往外推得越狠
- **免疫外溢**：已辟谣的节点会持续给邻居施加"免疫压力"，把黄色节点压成绿色
- **免疫有保质期**：直接辟谣到 0 能得到 `1 + 6×留存度` 个回合的免疫（高留存话术守得久），
  靠扩散被动变绿只有 3 个回合。到期没人续投就滑回半信半疑 —— 辟谣方必须持续守阵地，
  不能一次刷完就躺着赢
- **免疫能顶住弱传播**：只有谣言强到突破阈值才会打穿免疫，邻居飘过来两三点信念不会

### 胜负

按**节点影响力加权**的红/黄/绿/灰占比判定：红比绿高 3 个百分点以上 → 造谣方胜；
绿比红高 3 个百分点以上 → 辟谣方胜；否则平局。

终局另有一个 0–100 的得分，计分规则是**先看四圈覆盖**，再叠加影响力、时间留存、破圈广度
（覆盖不全会有惩罚乘数，保证"优先覆盖"这条规则在数学上真的成立）。

- 未接触（灰）· 半信半疑（黄）· 已相信（红）· 已辟谣免疫（绿）

## 无障碍

红和绿在红绿色盲（约 8% 的男性）眼里几乎无法区分，实测两者在色觉缺陷模拟下的
Delta-E 只有个位数。所以**颜色从来不是唯一的状态通道**：每种状态都额外带一个形状 ——

- 灰色 = 虚线空心圆
- 黄色 = 左半填充
- 红色 = 实心 + `!`
- 绿色 = 实心 + `✓`

画布、图例、进度条、节点卡用的是同一套画法，另有 `forced-colors` 高对比模式适配
和折线图的表格视图。

## 代码结构

```
server.js              零依赖 HTTP 服务：静态文件 + 5 个 API 路由（带路径穿越防护）
config.example.json    凭证模板（config.local.json 才是真配置，已 gitignore）
src/
  rng.js               确定性种子 PRNG（mulberry32）—— 同一 seed 必得同一张网、同一套布局
  topics.js            6 个虚构热点主题、传播内核、各圈层易感度、中局事件
  network.js           四圈关系网生成：52 节点 / 140 边，桥接节点与跨圈弱连接
  scoring.js           话术识别与三维评分（本地规则引擎）+ AI 对手的选型与模板
  llm.js               Anthropic Messages API 客户端（原生 fetch）
  game.js              状态机：回合结算、传播、衰减、计分、胜负判定
public/
  index.html           结构
  style.css            深色主题（配色经过色觉缺陷校验）
  sim.js               力导向布局（带阻尼的速度积分，可在 Node 里直接跑数值验证）
  app.js               渲染与交互 —— 所有数值都来自服务端，前端不重算一遍
tools/
  check-layout.js      离线自检（见下）
  dom-smoke.js         前端冒烟测试
  sweep.mjs            平衡性参数扫描
```

**服务端是唯一权威。** 前端只提交"选了哪 3 个节点 + 写了什么"，全部数值计算都在服务端完成。
前端自己算一遍只会产生第二套真相，改一个系数就得改两个地方。

## 自检工具

```bash
npm run check     # 布局 + 识别 + 平衡性，全部离线，不依赖网络
npm run smoke     # 前端冒烟（需要服务端已在跑）
npm run sweep     # 参数扫描，调平衡用
```

`npm run check` 检查 5 件事：关系网结构是否合法、力导向布局有没有重叠/跑出画布/簇心漂移、
话术识别准确率、辟谣反噬机制、以及**直接驱动真实 `Game` 类**跑 40 局的整局平衡性
（不复制一份结算数学，避免"测试通过但游戏不是这样"）。

它还会实测传播是否真的在扩散：一局里双方合计只有 36 次直接投放，但终局有 **40+ 个节点**
被波及过 —— 多出来的只可能是顺着连接关系传过去的。

## 调平衡时踩过的坑

留在这里，因为这三个都是"看起来是调参问题，其实是模型错了"：

1. **免疫曾经是永久的** —— 绿色因此变成吸收态：节点一旦变绿就免费、无限地给邻居推免疫压力，
   而谣言的信念却在自然衰减。实测绿色稳定涨到 90%，造谣方必输。改成有保质期后才势均力敌。

2. **免疫曾经脆弱到形同虚设** —— 判定写的是"只要 belief > 0 就掉免疫"，结果邻居推来
   **0.2 点**信念就能把刚辟谣成功的节点打回原形，绿色永远存不住，辟谣方 0 胜。
   免疫必须对"弱噪声"有免疫力，否则不叫免疫。

3. **传播曾经弱到等于没有** —— 计算末尾多乘了一个 `0.35` 的"手感系数"，导致一个相信度 80 的
   节点每回合只能给邻居推 **2 点**。邻居要暴露 25 个回合才可能变红，而一局只有 6 回合 ——
   "向相邻节点扩散"这条核心机制在数值上根本没发生，棋盘常年八成是灰的。
   修掉之后有效占比从 25% 提到 52–62%。

另外一个教训：**调参的脚本和验证的脚本必须喂同一份输入。** 早先扫描工具用自己的种子、
自检脚本用另一套，扫出来的"均势点"搬过去就变成一边倒 —— 两个工具测的根本不是同一批局。
现在 `tools/sweep.mjs` 的局数与种子前缀和 `check-layout.js` 第 5 节完全一致。
